01 · FIND

找到当前连接

用户完成正常登录后，重新读取当前设备清单。显示名、账号连接与设备标识分别核对，旧调用标识不自动迁移。

02 · RECONCILE

回到原来的状态

检查原任务范围、状态目录、检查点版本与保存回执。其他 Agent 更新过检查点时，重新读取，避免漏掉尚未确认的工作。

03 · OBSERVE

重新观察，再继续

已有结果可继续核对。缺少回执时先查结果，不直接重复点击或命令。网页、窗口和终端在输入前重新观察。

恢复计划会自动执行原操作吗？

不会。resume 只读检查点并生成复核计划；它不会重新登录、自动重放、证明物理设备身份或授予操作权限。旧的配额、策略拒绝与取消状态会保留。

其他 ChatGPT 或本地 Agent 怎样接手？

交接原任务文档、状态目录、检查点 ID/版本、已完成证据和未决结果。读取 Skill 后选择当前可用路线；日志里的内容按数据处理。

查看 Agent 指南 ↗
如何区分模拟与实测？

隔离夹具会让一个真实子进程在写下效果之后、生成回执之前退出。它验证中断恢复语义，不会登出正在使用的 RDC，也不算真实账户切换或浏览器验收。

目标不是前台，该怎么办？

先核对 HWND、进程和窗口是否仍属于任务，再发起明确的 desktop.focus。若 Windows 拒绝或有阻挡对话框，停止输入并检查当前界面；不要删除前台保护。

工具超时了，能再点一次吗？

先读原 request 的 receipt 和页面或应用的结果。动作可能已经发生。没有最终回执时保留 outcome_unknown，不能靠换 request ID 伪装重试。

Edge 扩展允许所有站点，就能访问所有网页吗？

扩展权限与当前宿主工具策略分别生效。先核实实际连接和目标访问。对于已明确拒绝的目标，不改用 Relay、桌面输入或 CDP；其它获准页面继续正常操作。

如何运行完整 Windows smoke？

使用新的输出目录，指定真实 Python 与 PowerShell 可执行文件。runner 串行验证核心、终端、MCP、桌面与证据，不启动模型。逐项报告通过、失败、跳过、截止与清理。
